# NewsHub

A responsive news application built with React and Material UI where users can browse the latest news by category and search for articles.

**Live Demo https://news-hub-frontend-gray.vercel.app
## Features

- Browse news by category
- Search for articles
- Light and dark mode


## Tech Stack

- React
- Material UI (MUI)
- Redux
- [Node.js, Express, MongoDB]

## Getting Started

1. Clone the repository
   `git clone https://github.com/zeenat2026/News-Hub.git`

   ### Frontend

1. Open a new terminal and go to the client folder
   `cd News-Hub/client/my-app`
2. Install dependencies
   `npm install`
3. Start the app
   `npm run dev`

   ### Backend
1. Go to the backend folder
   `cd News-Hub/backend`
2. Install dependencies
   `npm install`
3. Create a `.env` file and add your API key
   `NEWS_API_KEY=your_api_key_here`
4. Start the app
   `npm run dev`
